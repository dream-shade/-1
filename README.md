# 🧠 AI 第二大脑 (AI Second Brain)

这是一个专为大学生打造的个人复盘助手。通过调用大语言模型（DeepSeek），帮你总结每天的输入，并给出实质性建议，实现个人知识管理与成长记录。

## ✨ 核心功能
- **每日复盘**：输入今日收获与烦恼，AI 秒级总结并给出导师级建议。
- **数据持久化**：自动保存为 Markdown 格式，在左侧侧边栏随时回顾历史记录。
- **隐私安全**：API 密钥与私人日记完全本地存储，绝不泄露。

## 🛠️ 技术栈
- 语言：Python 3.x
- 框架：Streamlit (构建 Web UI)
- AI 接口：DeepSeek API (兼容 OpenAI SDK)
